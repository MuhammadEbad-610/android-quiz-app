Android Quiz App

Project Overview:

This project is a simple Quiz Application developed using Java in Android Studio.
The app presents multiple-choice questions to the user and calculates the final score based on correct answers.

The purpose of this project is to practice Android development fundamentals, including activities, user input handling, and basic UI design.

🚀 Features

Multiple choice quiz questions

User selects answers using buttons

Score calculation at the end of the quiz

Simple and clean user interface

Navigation between quiz screens

🛠️ Technologies Used

Kotlin

Android Studio

XML for UI Design

Android SDK

📂 Project Structure

The project follows a standard Android project structure created in Android Studio including:

MainActivity – Handles the quiz logic

Activities – Manage different screens

XML Layouts – Design the user interface

Resources – Strings, layouts, and assets
